## 📄 Beta Change Log
This is a prelease version of the 0.7.0 update. Minor issues may occur.
***

### 🎉 New Features!
- Added new yard limit sign!
- Added one-sided crossing light!

### ⚙️ Improvements
- Updated all mod dependencies
- Updated collision boxes for certain blocks on 1.12
- Updated iron pole texture
- Updated crossing light models
- Crafting recipes should now appear in crafting mensu when the correct conditions are met

### 🐛 Bug Fixes
- Fixed a broken texture on the railroad crossing light blocks
- Fixed 1.12 blocks being unbreakable (still requires an axe to break)
- Fixed data generation on 1.18 causing Forgix to generate a broken jar file
- Fixed crafting recipes, block drops, and other block data not working properly on some versions
- Fixed some blocks having weird or missing particle effects

### 🌐 Translations
- Updated English translations with new blocks (other translations will require an update)

### 🔧 Developer Changes
- Added datagen to most versions to improve reliability, add more features, and speed up new releases
- Added Dependabot to help catch outdated dependencies
- Added automatic build testing and publishing to GitHub actions
- Ended support for NeoForge on 1.20.x
- Improved mod consistency between versions
- Removed references to test blocks and test textures
- Removed obsolete JSON files (replaced by datagen)
- Update version to 0.7.0-beta
- Several other minor changes and improvements
